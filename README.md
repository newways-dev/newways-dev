## About

I'm a software developer in Hamburg, working at **Serrala**. I started with freelance web projects, moved to Germany at 21 and kept building.

At work I build REST backends with Java and Spring Boot, Angular frontends and internal tools. On the side I build products end to end, from the database to the UI.
